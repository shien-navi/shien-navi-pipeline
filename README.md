# shien-navi-pipeline

地域資源ナビゲーション基盤における、データ取得・マスタ連携・配信フォーマット生成を担うパイプライン用リポジトリです。

## 位置づけ
- **正本（Single Source of Truth）**: Google ドライブ（`01_マスタデータ`）上のスプレッドシート（`事業所マスタ`、`WAM同期管理`、`サービス種別辞書`、`タグ辞書`）および生データ（`WAM_RAW`）
- **本リポジトリの役割**: WAM NET 詳細データ取得、マスタ・タグ辞書との接続、配信用データ（`facilities.json` / `tags.json` / `facilities.csv`）の生成スクリプト・仕様の管理

## ディレクトリ構成（予定）
- `gas/` : Google Apps Script（`.gs`）ファイル群
- `schemas/` : 辞書・入出力データのサンプルや仕様定義
- `docs/` : アーキテクチャ・運用ルール・設計メモ

## セキュリティ・運用ルール
- スプレッドシートIDやフォルダIDなどの環境固有値はコードに直書きせず、GAS の `ScriptProperties` で管理します。
